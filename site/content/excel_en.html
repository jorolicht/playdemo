Installation Instructions TTC Tournament Software

  • 1
    Download & Extract:
    Download the ZIP files (program and optional help archive) and extract them onto your computer.
  • 2
    Macro Enable in Excel:
    When opening the Excel file (TTC Tournament Software), the execution of macros/VBA code must be allowed in Microsoft Excel.
  • 3
    System Requirements (MSXML):
    The required Microsoft Core XML Services (MSXML) 6.0 are usually pre-installed on all modern Windows systems and do not need to be installed separately.
  • 4
    Printer & Paper Format Setup (DIN A4):
    All print outputs are optimized for DIN A4 paper size. It is recommended to set this paper format as default. In Windows 7, for example, proceed as follows: go to Control Panel > Hardware and Sound > Devices and Printers, select your desired printer, and set the paper quality under Printer Properties (right-click on the printer icon).
