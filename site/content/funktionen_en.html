Tournament Software Features

Powerful Features at a Glance

The modern complete solution for table tennis tournaments. From flexible stage planning and mobile QR code result entry to live hall displays.

Realtime WebSockets Mobile QR-Code Scanner ClickTT Import/Export Scala 3 & Scala.js

Combinable Stage Formats

Seamlessly combine various tournament modes into a single event. Configure preliminary and main rounds with full flexibility.

  • Group Stage: Round-robin groups with automatic table standings & set ratio calculations
  • Knockout System: KO brackets with bye handling, placement matches & auto-progression
  • Swiss System: Balanced rounds featuring Buchholz tie-break evaluation

2 to 4 Winning Sets

Customise match set rules individually per competition or tournament stage.

  • Best-of-3 (2 winning sets) for fast group stages
  • Best-of-5 (3 winning sets) as standard format
  • Best-of-7 (4 winning sets) for high-stakes finals

Intelligent Draw & Seeding

Automated and fair group & bracket draws based on player TTR ratings and club protection.

  • Automatic avoidance of same-club duels in group stages
  • Seeding of top group heads by TTR ranking
  • Manual adjustment & swap options before tournament start

Result Entry & Time Tracking

Ultra-fast score recording using keyboard shortcuts and automatic timestamp tracking.

  • Shortcut entry (e.g., -5 for 5:11, 10 for 12:10)
  • Start & end times formatted as HH:MM
  • Automatic set validation & tie-break checking

Referee Scoresheets (Print)

Print-ready score sheets featuring QR codes in a clean 4-up A4 layout.

  • Print by round, group, or single match
  • Compatible with all standard office printers
  • Embedded QR codes for direct mobile result submission

ClickTT Support

Seamless import and export of ClickTT XML files for rapid data exchange.

  • Import player lists, clubs, and TTR ratings
  • Export completed tournament results back to ClickTT
  • Automatic player ID matching
Mobile Innovation

Player Result Submission via QR Code

Every printed referee sheet includes a unique QR code. Players or referees simply scan the code with their smartphone camera to submit set scores on the spot.

  • Instant real-time transmission to tournament control via WebSockets
  • Blinking red info button alerts tournament directors of new submissions
  • No app installation required – works in any mobile web browser
