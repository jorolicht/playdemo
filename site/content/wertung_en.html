Scoring System

How TurnierService scores sets, matches and team ties and calculates tables – from a single point to the final placing. Described here is the table tennis scoring system, version 2.

1. Overview

The scoring system defines the rules of a sport: when a set and a match are won, how a team tie ends and in which order the table is decided. It is built in levels; each level counts the units won on the level below:

Which rules apply is stored in the competition: every competition keeps the version of its scoring system (section 11) and is always scored by it – even when new rules are added later.

2. Set

A set is played to 11 points. It is won by the side that reaches 11 points with a lead of at least 2 points. At 10:10 play continues until one side leads by 2 points (12:10, 13:11, …); there is no upper limit.

3. Match and sets to win

A match is won by whoever first wins the required number of sets. You set the sets to win per stage in the administration:

A match cannot end in a draw. When saving, the program checks that every set is valid and that exactly one side has reached the required number of sets.

4. Short notation

Because the winner of a set almost always has 11 points, one number per set is enough: the loser’s points, positive if player A (left) wins the set, negative if player B wins. The program adds the winner’s points.

Example of a match with 3 sets to win: 5, -9, 10, 3 gives 11:5, 9:11, 12:10, 11:3 – 3:1 for player A.

5. Byes and walkovers

  • Bye in a knockout: A player drawn against a bye wins by walkover and automatically moves on to the next round. The match counts with the full sets to win (e.g. 3:0), without points.
  • Bye in the Swiss system: With an odd number of participants one player receives a bye each round; it counts as a win (section 7).
  • Missing player in a team tie: If a position is not filled, the other team wins that match by walkover with the full sets to win. If both players are missing, the match counts for nobody.

6. Tables: groups and round robin

In groups, in round robin and in the overall table of a double round robin (first and second leg), the table is calculated from all scored matches. The order is decided by these criteria in turn – the next one only counts when two participants are equal in the previous one:

Example: Anna and Ben have each won 2 matches and lost 1 (match difference +1). Anna won her sets 7:4 (+3), Ben 6:4 (+2) – Anna ranks ahead of Ben. If the sets were equal too, the point difference would decide.

If two participants are equal in all criteria, they share the same place (e.g. place 2 twice, then place 4). The head-to-head result is currently not taken into account. You then decide who advances in the draw of the next stage.

For teams a drawn tie (e.g. 5:5 in the Braunschweig system) counts neither as won nor as lost; it does not change the tie difference.

7. Swiss system

In the Swiss system not everyone plays everyone; a new draw follows each round. The table is ordered by:

  1. wins (a bye counts as a win),
  2. Buchholz score: the sum of the wins of all previous opponents (byes do not count as opponents) – with the same number of wins, whoever faced stronger opponents ranks higher,
  3. set difference,
  4. TTR rating.

The draw of the next round follows these rules, in this order: no pairing twice and no second bye for the same player; the bye goes to a player of the lowest score group; players with the same number of wins play each other; club protection; ratings as similar as possible, with the bye going to the weakest player.

8. Knockout

In a knockout the winner of each match moves on to the next round and the loser is eliminated (in double elimination the loser moves to the losers’ bracket). The placing follows from the round in which a participant is eliminated; the match for 3rd place decides places 3 and 4.

A knockout tie always needs a winner. For teams (section 9): if the score is level after all matches, the decider match or the set and point difference decides.

9. Teams: the tie

In team competitions the level tie is added above the match: two teams play several singles and doubles in a fixed order of play; every match won is one point for the team. You choose the team system (section 10) per stage in the administration, together with a mode:

  • First to n points: play continues until one team has n points; the remaining matches are dropped (e.g. Bundessystem: ends at 3:0, 3:1 or 3:2).
  • All matches: all matches in the order of play are played; the team with more points wins (e.g. Bundessystem “All 5 matches”: 4:1 or 5:0 are possible too).
  • Draw: some systems allow a draw (e.g. 2:2 in the Swaythling Cup, 7:7 with teams of four, 5:5 in the Braunschweig system). In the table it counts neither as a win nor as a loss.
  • Decider: a decider match (e.g. the deciding doubles in the Swaythling Cup) is only played if the score is level after all other matches and the chosen mode provides for it.

Draws in knockout rounds

There are no draws in knockout rounds:

  • If the system has a decider match (Swaythling Cup), it is always played when the score is level.
  • With “first to n points” and a possible draw (teams of four and six, e.g. 7:7), the team with the better set difference over all matches of the tie wins; with equal set difference the better point difference decides.

Before results are entered, both teams submit their line-up (positions A1, A2 … or B1, B2 … and doubles). Once the tie has started, the line-up can no longer be changed.

11. Scoring system versions

Rules change: new team systems are added, modes are extended. So that a running or finished tournament is not suddenly scored differently, the scoring system is versioned:

  • A published version is never changed again; new rules appear as a new version.
  • A new competition receives the latest version. You see it in the administration of the stage under “Scoring system” and can change it there until the first draw.
  • Competitions from older tournaments keep their version, even after a program update. If an installation does not know a version (e.g. a tournament from a newer installation), it calculates with its latest version and shows a notice.
