Tourney WordPress Plugin

Verwandeln Sie Ihre WordPress-Website in eine vollständige Turnierverwaltung für Tischtennis und Turniersport – einfach per Shortcode auf jeder beliebigen Seite.

Download tourney-embed-1.0.6.zip

Funktionen des Turnierprogramms

Vielseitige Turniersysteme

Unterstützt Einzel- und Doppel-Wettbewerbe mit Gruppenphase, KO-System (Haupt- & Trostrunde), Schweizer System und Jeder-gegen-Jeden (Round Robin).

Spieler, Vereine & ClickTT

Komfortable Teilnehmer- und Vereinsverwaltung inklusive Import aus ClickTT-Dateien, Setzlisten nach TTR/QTTR sowie automatischer Auslosung.

Ergebniseingabe & Druck

Schnelle Live-Ergebniserfassung, automatische Tabellen- und Platzierungsberechnung sowie Druck von Schiedsrichterzetteln, Ergebnislisten und Urkunden.

Direktspeicherung & Lokal-Modus

Turniere können direkt in der jeweiligen WordPress-Seite gespeichert und veröffentlicht oder im Browser lokal getestet (Demo & Schnellstart) werden.

Installation & Verwendung in WordPress

Das Plugin lässt sich in wenigen Schritten in jeder WordPress-Installation einrichten und direkt über den Shortcode [tourney] nutzen:

  • 1
    Plugin herunterladen:
    Laden Sie das Installationsarchiv tourney-embed-1.0.6.zip herunter.
  • 2
    In WordPress hochladen & aktivieren:
    Öffnen Sie im WordPress-Adminbereich Plugins > Neues Plugin hinzufügen > Plugin hochladen, wählen Sie die Datei tourney-embed-1.0.6.zip aus, klicken Sie auf Jetzt installieren und anschließend auf Plugin aktivieren.
  • 3
    Shortcode in eine Seite einfügen:
    Erstellen Sie eine neue WordPress-Seite (oder öffnen Sie eine bestehende Seite) und fügen Sie im Editor (als Shortcode-Block oder Text) einfach folgenden Shortcode ein:
    [tourney]
  • 4
    Turnier erstellen & verwalten:
    Rufen Sie die veröffentlichte Seite auf. Sie sehen die Startansicht mit Demo, Neues Turnier und Schnellstart. Sobald Sie ein Turnier auf dieser Seite anlegen, wird es direkt in dieser Seite gespeichert. Besucher sehen automatisch die Turnierübersicht und Ergebnisse; angemeldete Benutzer mit Schreibrechten können das Turnier direkt auf derselben Seite verwalten und bearbeiten.

Aktuelle Version & What's New

Version 1.0.6 (31.10.2026)

Neuerungen in Version 1.0.6:

  • Verständliche Login-Fehler: Ein falsches Passwort wird im Fehlerdialog mit klarem Text angezeigt; technische Details nur auf Wunsch.
  • Wettbewerbe als Baum: In der Turnier-Info lassen sich Wettbewerbe mit ihren Stages aufklappen; die Reiter jeder Stage sind direkt anklickbar.
  • Reiter Urkunden: In der Urkunden-Phase zeigt ein eigener Reiter die Ergebnisse mit einem Urkunden-Button pro Spieler.
  • Fehlerdialog mit Details: Fehler erscheinen in einem Dialog mit Code und Aufrufstelle statt als Browser-Meldung.
  • Stabile Anmeldung: Nach Login, Logout und Passkey-Registrierung funktionieren alle Aufrufe ohne Neuladen.
