Version History

Overview of all versions, new features, and improvements in TurnierService.

Version 1.5.2 25.11.2026
New: links to TTC Freising Lerchenfeld and the BTTV in the footer.
  • The website footer now links to TTC Freising Lerchenfeld e.V. (ttcfreising.org) and the Bavarian Table Tennis Association (bttv.de).
Version 1.5.1 24.11.2026
New: online registration with waiting list and email confirmation.
  • In the “Edit competition” dialog you can set a maximum number of participants. Once it is reached, further online registrations go on the waiting list; the tournament page shows the available places. When a place becomes free (participant removed or maximum raised), players move up automatically in order of registration. Players who enter an email address receive a confirmation of their registration or waiting list position and an email when they move up.
Version 1.5.0 2026-11-23
New: copy a tournament – template from last year.
  • In the tournament overview, “Copy” creates the template for your next tournament: competitions with their stages, start times, venue, contact and homepage texts (for cloud tournaments also the logo) – without players and results. All dates are moved to the new date; when you start a stage, its name and system are pre-filled.
Version 1.4.9 2026-11-23
Demo tournament: running matches show a realistic playing time.
  • In the demo tournament, result entry showed the entire time since the demo data was recorded as the playing time of running matches. Running matches now start a few minutes before the demo is opened.
Version 1.4.8 2026-11-23
Help & user guide now also in English.
  • The user guide is now available in English at /en/help/, with screenshots of the English interface. The tournament page and the draw are now fully translated in the English interface.
Version 1.4.7 2026-11-23
New: help & user guide with screenshots (German).
  • New “Help” menu item: step-by-step guide with screenshots for tournament directors and players (currently in German; the English version is in preparation).
Version 1.4.6 2026-11-21
Swiss system: optimal pairing of subsequent rounds.
  • Swiss pairing now always finds the best pairing (blossom matching): players with equal scores meet, rematches are avoided, club protection and similar TTR ratings; the bye goes to the weakest player of the lowest score group, never twice to the same player.
Version 1.4.5 2026-11-21
Feature overview updated: teams, online registration, “My Tournament” and more.
  • “Features” page: double elimination and double round robin, team competitions with all systems, online registration, “My Tournament”, several editors, certificates with custom logo, offline app and backup.
Version 1.4.4 2026-11-21
Single tournament and 5-pack can now be bought online.
  • “Support/Pricing” page: single tournament (€9.90) and 5-pack (€34.90) can be bought via Payhip; the credit is added automatically and is valid for 2 years.
Version 1.4.3 2026-11-21
New pricing: single tournament, 5-pack, club and association licence.
  • “Support/Pricing” page: Offline Standard with all features, free forever; Cloud Live Pro with trial tournament (€0), single tournament (€9.90), 5-pack (€34.90), club licence (€79/year) and association licence (from €249/year).
  • A cloud tournament is reserved when created; if it is deleted without results, the credit is returned. Purchased tournaments are valid for 2 years.
  • Cloud tournaments are archived 1 year after they end: read-only, results stay publicly visible. No archiving with a club or association licence.
Version 1.4.2 2026-11-21
Custom logo per tournament on the tournament page and certificates.
  • Tournament administration, “Homepage” tab: upload or remove a logo (PNG, JPG or WebP up to 2 MB; resized to 400 px). Cloud tournaments only.
  • The logo appears on the tournament page and on the default certificate; in custom certificate templates the placeholder #Logo inserts it.
Version 1.4.1 2026-11-21
“My Tournament”: personal view for players with next matches, results and standings.
  • On the tournament page, the “My Tournament” button opens the personal view. Players select their name, no account needed; the browser remembers the choice.
  • It shows the next matches with opponent – called matches first, with table –, the player's results and, per competition, the standing in the group or the position in the knockout draw (e.g. “Next round: Semifinal”).
  • Singles and doubles; the view refreshes every 30 seconds.
Version 1.4.0 2026-11-21
Online registration for competitions, multi-user editing with change log.
  • Online registration: on the tournament page, players register for a singles competition with last name, first name, club and TTR rating (optionally year of birth, email, WhatsApp), protected by a captcha. Registered players get the status “registered”.
  • Edit competition: registration period “from/until” and checkbox “Registration closed”. The competition list shows “Register now … until”, “Registration from …” or “Registration closed”.
  • Tournament administration, “Homepage” tab: note shown after online registration (default: “Please report to the tournament desk at least 30 minutes before the competition starts …”). If registration is not enabled, the tournament director sees a hint in the competition list.
  • Privacy: players' email addresses and WhatsApp numbers are only available to editors of the tournament.
  • Multi-user editing: results entered by other editors appear immediately; simultaneous entries are merged per match (“last entry wins” with a notice). New “Changes” tab with the change log.
  • Tournament page: GDPR-compliant map of the venue (OpenStreetMap, served by our own server).
  • My Tournaments: “Export tournament to file” for the local and the opened cloud tournament; the “Import / Export” tab in the administration is removed (it remains in the WordPress plugin).
Version 1.3.1 2026-11-18
Daily statistics mail to the website administrator.
  • Statistics: every morning at 8 a.m. the website administrator receives the usage figures (yesterday, last 7 and 30 days, previous month) by email.
Version 1.3.0 2026-11-18
New modes: double round robin (first and second leg) and double elimination.
  • Mode “double round robin”: first and second leg with mirrored pairings, combined table of both legs.
  • Mode “double elimination”: winners and losers bracket with final, optionally with a reset match; placement of all participants.
  • Linked stages are shown, switched and deleted together.
Version 1.2.2 2026-11-18
ClickTT menu in the tournament overview, consistent start buttons and finalizing in the administration.
  • ClickTT: import, update and export via the “ClickTT” menu in the tournament overview (previously administration or “Load ClickTT data”).
  • Start buttons (create tournament, playing phase, successor, Swiss system rounds) consistently with a start icon.
  • “Finalize competition” also in the administration of a stage.
  • Demo results for teams: each player in only one doubles match.
Version 1.2.1 2026-11-18
Fixes: team lineup, draw start button and Offline App hint.
  • Team lineup: each player can only be fielded in one doubles match.
  • Draw: the start button names the stage (“⤳ Start <name>”).
  • Offline App: the backup hint refers to “My Tournaments → Export tournament to file”.
Version 1.2.0 2026-11-17
Team competitions, scoring systems per sport and a reworked competition workflow.
  • Team competitions for teams of 2, 3, 4 and 6 players with matching team match systems and result entry per encounter; teams can also be created via CSV import.
  • Scoring systems per sport, versioned and fixed per competition.
  • Competition sections: start a successor directly from the section list or the results, finalize a competition with a certificates section.
  • Draw is locked once matches have started; started competitions can only be edited partially.
  • Menu “My tournaments”, consistent dialogs, CSV import with year of birth, email and WhatsApp.
  • Printing: all referee sheets and stage results are printed completely.
Version 1.1.0 2026-11-04
New offline app: organize tournaments in your browser without internet, installable as an app.
  • Menu Tools → Offline App: the page can be installed as an app on smartphones, tablets and computers.
  • After the first visit, the app works without an internet connection.
  • Tournaments are stored locally in the browser and backed up by exporting to a JSON file.
Version 1.0.8 2026-11-02
New colors on the home page, a more compact layout, and a new contact email address.
  • Home page: new colors for the icons and buttons of the four entry points.
  • Home page: the footer follows the content directly.
  • Contact: email address info@turnier-service.org.
Version 1.0.7 2026-11-01
Fix: emails (registration, password) are sent through the configured mail server again.
  • Since version 1.0.4, emails were redirected to a test server and never arrived; the mail setup configured in WordPress applies again (also in the embeddable plugin).
Version 1.0.6 2026-10-31
Login errors in the error dialog with details, plus search engine fixes.
  • Wrong password and other sign-in errors appear in the error dialog with a readable message; code and call site via "Details".
  • Website: the registration page is no longer indexed by search engines.
Version 1.0.5 2026-10-31
Competition list as a tree with stages, certificates tab, error dialog with details, plus page URLs and an English version of the website.
  • Tournament info: competitions with stages expand as a tree; each stage's tabs can be opened directly.
  • New stage tab "Certificates" in the certificate stage: result view with a certificate button per player.
  • Error dialog with details (code, call site) instead of a browser alert.
  • Valid session after login/logout and passkey registration without reloading.
  • Website: home and info pages directly in the HTML, own URLs (e.g. /en/pricing/), English version under /en/ with a language switcher.
  • Website: social media links in the footer and anonymous usage statistics.
Version 1.0.4 2026-10-25
Embeddable plugin with download area, permission checks based on write access, unified creation, and a warning for unsaved changes.
  • Two variants: website version and embeddable WordPress plugin (tourney-embed) with a public download area.
  • Start view depends on write access to the page; write requests are secured on the server.
  • Unified creation of demo, tournament, and competition with overwrite confirmation.
  • Warning when leaving the page while changes have not been saved yet.
  • Result list: the selected certificate stage is now also evaluated for knockout stages.
Version 1.0.3 2026-10-19
Status bar for last tournament (Local/Cloud) with quick load & delete, streamlined demo start, and improved stage/result entry.
  • Status bar on the home page for directly loading or deleting the most recently used local or cloud tournament.
  • Direct start of the demo tournament without confirmation dialog when the last tournament was saved in the cloud.
  • Improved stage rendering, Group/Round Robin draws, score sheets, and result input.
  • SemVer versioning, automatic asset cache-busting, and streamlined WordPress plugin deployment.
Version 1.0.2 2026-09-01
Cloudflare Turnstile CAPTCHA protection for registration, extended backup configuration, and Docker improvements.
  • Added Cloudflare Turnstile CAPTCHA for user registration and forms.
  • Extended production and backup configuration (Traefik, Google Drive backup).
  • Refined stage layouts and internationalization (DE/EN).
Version 1.0.1 2026-08-15
Shortcode options for display modes and WebAuthn/Passkey support.
  • Provided shortcode options for different display modes (pure, home, view).
  • Extended WordPress REST API with WebAuthn/Passkey endpoints.
Version 1.0.0 2026-08-01
Initial release of the Tourney WordPress Plugin with Scala.js client integration.
  • Complete tournament management (Group stage, KO system, Swiss system, Round Robin) as a reactive Single-Page Application.
  • Seamless WordPress integration via Custom Post Type tourney and REST API.
  • Support for local/offline mode in the browser as well as cloud synchronization.
