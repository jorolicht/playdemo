Version History

Overview of all versions, new features, and improvements in TurnierService.

Version 1.0.6 2026-10-31
Login errors in the error dialog with details, plus search engine fixes.
  • Wrong password and other sign-in errors appear in the error dialog with a readable message; code and call site via "Details".
  • Website: the registration page is no longer indexed by search engines.
Version 1.0.5 2026-10-31
Competition list as a tree with stages, certificates tab, error dialog with details, plus page URLs and an English version of the website.
  • Tournament info: competitions with stages expand as a tree; each stage's tabs can be opened directly.
  • New stage tab "Certificates" in the certificate stage: result view with a certificate button per player.
  • Error dialog with details (code, call site) instead of a browser alert.
  • Valid session after login/logout and passkey registration without reloading.
  • Website: home and info pages directly in the HTML, own URLs (e.g. /en/pricing/), English version under /en/ with a language switcher.
  • Website: social media links in the footer and anonymous usage statistics.
Version 1.0.4 2026-10-25
Embeddable plugin with download area, permission checks based on write access, unified creation, and a warning for unsaved changes.
  • Two variants: website version and embeddable WordPress plugin (tourney-embed) with a public download area.
  • Start view depends on write access to the page; write requests are secured on the server.
  • Unified creation of demo, tournament, and competition with overwrite confirmation.
  • Warning when leaving the page while changes have not been saved yet.
  • Result list: the selected certificate stage is now also evaluated for knockout stages.
Version 1.0.3 2026-10-19
Status bar for last tournament (Local/Cloud) with quick load & delete, streamlined demo start, and improved stage/result entry.
  • Status bar on the home page for directly loading or deleting the most recently used local or cloud tournament.
  • Direct start of the demo tournament without confirmation dialog when the last tournament was saved in the cloud.
  • Improved stage rendering, Group/Round Robin draws, score sheets, and result input.
  • SemVer versioning, automatic asset cache-busting, and streamlined WordPress plugin deployment.
Version 1.0.2 2026-09-01
Cloudflare Turnstile CAPTCHA protection for registration, extended backup configuration, and Docker improvements.
  • Added Cloudflare Turnstile CAPTCHA for user registration and forms.
  • Extended production and backup configuration (Traefik, Google Drive backup).
  • Refined stage layouts and internationalization (DE/EN).
Version 1.0.1 2026-08-15
Shortcode options for display modes and WebAuthn/Passkey support.
  • Provided shortcode options for different display modes (pure, home, view).
  • Extended WordPress REST API with WebAuthn/Passkey endpoints.
Version 1.0.0 2026-08-01
Initial release of the Tourney WordPress Plugin with Scala.js client integration.
  • Complete tournament management (Group stage, KO system, Swiss system, Round Robin) as a reactive Single-Page Application.
  • Seamless WordPress integration via Custom Post Type tourney and REST API.
  • Support for local/offline mode in the browser as well as cloud synchronization.
