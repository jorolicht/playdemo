Tournament Software Features

Versatile Tournament Modes

Supports singles and doubles competitions with group stages, knockout brackets (main & consolation), Swiss system, and Round Robin.

Players, Clubs & ClickTT

Convenient participant and club management including ClickTT XML import, TTR/QTTR seeding lists, and automated draws.

Live Scoring & Printing

Fast live score entry, automatic standings calculation, and print-ready referee score sheets, result lists, and certificates.

Direct Page Storage & Local Mode

Tournaments can be saved and published directly inside the WordPress page or tested locally in the browser (Demo & Quick Start).

Installation & Usage in WordPress

The plugin can be installed in any WordPress site in just a few steps and used directly via the [tourney] shortcode:

  • 1
    Download the Plugin:
    Download the installation archive tourney-embed-1.0.6.zip.
  • 2
    Upload & Activate in WordPress:
    In your WordPress admin dashboard, go to Plugins > Add New Plugin > Upload Plugin, select tourney-embed-1.0.6.zip, click Install Now, and then click Activate Plugin.
  • 3
    Insert the Shortcode into a Page:
    Create a new WordPress page (or open an existing page) and insert the following shortcode in the editor (as a Shortcode block or text):
    [tourney]
  • 4
    Create & Manage Your Tournament:
    Open the published page. You will see the start view with Demo, New Tournament, and Quick Start. As soon as you create a tournament on this page, it is saved directly into that page. Visitors automatically see the tournament overview and live results, while logged-in users with write permissions can edit and manage the tournament directly on the same page.
